Home Assistant Sensor (openhac4)

Exposes a Home Assistant sensor entity such as temperature, humidity, or power to Control4 for use in programming. Sensors are informational, so this driver has no navigator presence; the value is available as device variables and driver properties. Requires the openhac4 Gateway driver, installed and connected.

Setup

  1. Install and connect the Home Assistant Gateway (openhac4) driver first.
  2. Add this driver, or let the gateway's Import Devices add it. Import Devices skips sensors that have no unit of measurement, such as diagnostic and text sensors, so add those manually if you need them.
  3. Pick the sensor entity in the Entity property. Run Refresh Entity List if it is empty. Entity ID accepts a manually typed entity id.

Programming

  • Variables: SENSOR_VALUE, SENSOR_VALUE_NUMBER and UNIT. SENSOR_VALUE is a string. SENSOR_VALUE_NUMBER is numeric when the value parses as a number.
  • The driver also creates a read-only HA_<ATTRIBUTE> variable for each attribute the Home Assistant entity reports, named in upper case with non-alphanumeric characters replaced by underscores (an app_name attribute becomes HA_APP_NAME). A small set of metadata and high-churn attributes is skipped (friendly_name, icon, device_class, supported_features, attribution, entity_picture, and media position), and at most 100 are exposed per entity.
  • Events: Value Changed, Offline.
  • Properties Current Value and Unit mirror the latest reading.

Troubleshooting

  • Gateway Not Found: add and connect the openhac4 Gateway driver first.
  • Entity list empty: the gateway is not connected to Home Assistant yet, or has no entities of this type. Check the gateway's Connection Status, then run Refresh Entity List.
  • State stuck on Unavailable: the entity is unavailable in Home Assistant, or the selected entity id does not exist. A typo produces the same result. Confirm the entity id against Home Assistant.
