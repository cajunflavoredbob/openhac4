Home Assistant Media Player (openhac4)

Transport, volume, source, and now-playing control of a Home Assistant media_player from Control4. This is a control and status device: it does not appear as a room "Listen" audio source.

If you want the entity selectable as a room source, with browsing and a Now Playing screen, use Home Assistant Media Source (openhac4) instead. The two drivers can be used together on the same entity: this one for control and status, that one for the room source. Media Source is not created by Import Devices, so add it by hand when you want it. Import first and add Media Source second: Import Devices skips any entity already held by an openhac4 child, so a hand-added Media Source will hide that entity from the import.

Setup

  1. Add this driver; it finds the openhac4 gateway automatically.
  2. Set Entity to the media_player entity, or type its id into Entity ID. Use Refresh Entity List if it is not listed yet.

Actions / programming

  • Transport: Play, Pause, Play/Pause, Stop, Next, Previous, Turn On/Off.
  • Volume: Volume Up/Down, Set Volume from 0 to 100, Mute/Unmute.
  • Select Source: pick from the entity's source list.
  • Events: Playing / Paused / Stopped / Offline. Variables: STATE, MEDIA_TITLE, MEDIA_ARTIST, MEDIA_ALBUM, VOLUME, SOURCE, plus the HA_<ATTRIBUTE> variables described below, such as HA_APP_NAME.
  • The driver also creates a read-only HA_<ATTRIBUTE> variable for each attribute the Home Assistant entity reports, named in upper case with non-alphanumeric characters replaced by underscores (an app_name attribute becomes HA_APP_NAME). A small set of metadata and high-churn attributes is skipped (friendly_name, icon, device_class, supported_features, attribution, entity_picture, and media position), and at most 100 are exposed per entity.
