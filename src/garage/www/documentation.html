Home Assistant Garage Door (openhac4)

Presents a Home Assistant garage cover, a cover entity with device_class garage, as the classic Control4 garage building block: a momentary Relay plus a Closed Sensor and an Open Sensor.

Setup

  1. Add this driver; it finds the openhac4 gateway automatically.
  2. Set Entity to the garage cover entity.
  3. Add Control4's stock Garage Door driver and bind its relay and its two contact inputs to this driver's Relay, Closed Sensor, and Open Sensor connections. That stock driver provides the garage tile.

Notes

  • The relay is treated as momentary: a pulse toggles the door in Home Assistant. The contacts report position; while in transit, both read open.
  • Open, Close, Stop, and Toggle are available as actions and as programming commands.

Programming

  • Events: Opened, Closed, and Offline.
  • Entity ID accepts a manually typed entity id if the Entity picker is empty; Refresh Entity List repopulates the picker.
  • The driver also creates a read-only HA_<ATTRIBUTE> variable for each attribute the Home Assistant entity reports, named in upper case with non-alphanumeric characters replaced by underscores (an app_name attribute becomes HA_APP_NAME). A small set of metadata and high-churn attributes is skipped (friendly_name, icon, device_class, supported_features, attribution, entity_picture, and media position), and at most 100 are exposed per entity.
