Home Assistant Climate (openhac4)

Presents a Home Assistant climate entity in Control4 as a native thermostat, with HVAC mode, setpoints, current temperature, and fan mode. Requires the openhac4 Gateway driver, installed and connected.

Setup

  1. Install and connect the Home Assistant Gateway (openhac4) driver first.
  2. Add this driver, or let the gateway's Import Devices add it.
  3. Pick the climate entity from the Entity dropdown, or type the entity id into Entity ID.
  4. Set Temperature Scale to match your Home Assistant unit system, Fahrenheit or Celsius. If it does not match, setpoints will be wrong.

Programming

  • Command: Set HVAC Mode, one of Off, Heat, Cool, or Auto.
  • Events: Mode Changed, Offline.
  • Variable: HVAC_MODE.
  • The driver also creates a read-only HA_<ATTRIBUTE> variable for each attribute the Home Assistant entity reports, named in upper case with non-alphanumeric characters replaced by underscores (an app_name attribute becomes HA_APP_NAME). A small set of metadata and high-churn attributes is skipped (friendly_name, icon, device_class, supported_features, attribution, entity_picture, and media position), and at most 100 are exposed per entity.
  • Setpoints and mode are also controllable from the thermostat UI in navigators. In Auto mode the heat and cool setpoints control the low and high target; in Heat or Cool mode a single setpoint is used.
  • Fan mode is set from the thermostat UI in navigators when the Home Assistant entity reports fan modes.
  • Actions: Set Preset Mode and Set Swing Mode, each offering the modes the entity advertises. These are Composer actions rather than programming commands.

Notes

  • Current humidity is reported to the thermostat when the entity provides it, and appears in the read-only Current Humidity property.
  • Humidity setpoints and schedules are not exposed. Use a Home Assistant automation, or the gateway's Call Service action, for either.

Troubleshooting

  • Gateway Not Found: add and connect the openhac4 Gateway driver first.
  • Entity list empty: the gateway is not connected to Home Assistant yet, or has no entities of this type. Check the gateway's Connection Status, then run Refresh Entity List.
  • State stuck on Unavailable: the entity is unavailable in Home Assistant, or the selected entity id does not exist. A typo produces the same result. Confirm the entity id against Home Assistant.
