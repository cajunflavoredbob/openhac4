Home Assistant Lock (openhac4)

Presents a Home Assistant lock entity in Control4 as a native lock, with lock/unlock control and status in navigators and programming. Requires the openhac4 Gateway driver, installed and connected.

Setup

  1. Install and connect the Home Assistant Gateway (openhac4) driver first.
  2. Add this driver, or let the gateway's Import Devices add it.
  3. Pick the lock entity from the Entity dropdown, or type the entity id into Entity ID. Run Refresh Entity List if the dropdown is empty.

Programming

  • Commands: Lock, Unlock, Toggle.
  • Events: Locked, Unlocked, Jammed, Offline.
  • Variable: LOCK_STATE, one of locked, unlocked, unknown, or fault.
  • The driver also creates a read-only HA_<ATTRIBUTE> variable for each attribute the Home Assistant entity reports, named in upper case with non-alphanumeric characters replaced by underscores (an app_name attribute becomes HA_APP_NAME). A small set of metadata and high-churn attributes is skipped (friendly_name, icon, device_class, supported_features, attribution, entity_picture, and media position), and at most 100 are exposed per entity.

Troubleshooting

  • Gateway Not Found: add and connect the openhac4 Gateway driver first.
  • Entity list empty: the gateway is not connected to Home Assistant yet, or has no entities of this type. Check the gateway's Connection Status, then run Refresh Entity List.
  • State stuck on Unavailable: the entity is unavailable in Home Assistant, or the selected entity id does not exist. A typo produces the same result. Confirm the entity id against Home Assistant.
