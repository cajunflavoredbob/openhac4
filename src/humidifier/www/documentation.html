Home Assistant Humidifier (openhac4)

Controls a Home Assistant humidifier entity from Control4 programming: on/off, a target humidity setpoint, and mode selection. It has no navigator tile. This is a programming device; drive it from the Actions tab or programming.

Setup

  1. Add this driver; it finds the openhac4 gateway automatically.
  2. Set Entity to the humidifier entity, or type the id into Entity ID.

Actions / programming

  • Turn On / Turn Off / Toggle.
  • Set Humidity: target relative humidity from 0 to 100 percent.
  • Set Mode: pick from the entity's available modes.
  • Events: Turned On / Off / Offline. Variables: STATE, HUMIDITY, plus the HA_<ATTRIBUTE> variables described below, such as HA_CURRENT_HUMIDITY and HA_MODE.
  • The driver also creates a read-only HA_<ATTRIBUTE> variable for each attribute the Home Assistant entity reports, named in upper case with non-alphanumeric characters replaced by underscores (an app_name attribute becomes HA_APP_NAME). A small set of metadata and high-churn attributes is skipped (friendly_name, icon, device_class, supported_features, attribution, entity_picture, and media position), and at most 100 are exposed per entity.
