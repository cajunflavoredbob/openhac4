Home Assistant Switch (openhac4)

Presents a Home Assistant switch entity in Control4 as an experience button you tap to toggle, with a relay connection for programming and for Control4 relay consumer drivers. Requires the openhac4 Gateway driver, installed and connected.

Setup

  1. Install and connect the Home Assistant Gateway (openhac4) driver first.
  2. Add this driver to the room where the switch should appear, or let the gateway's Import Devices action add it for you.
  3. Pick the switch entity in the Entity property. If the list is empty, run the Refresh Entity List action. Entity ID accepts a manually typed entity id.
  4. Current State follows the entity immediately when it changes in Home Assistant.

Programming

  • Commands: Turn On, Turn Off, Toggle.
  • Events: Turned On, Turned Off, Offline. Events fire on real state transitions only, not on project load.
  • Variable: STATE, true when on.
  • The driver also creates a read-only HA_<ATTRIBUTE> variable for each attribute the Home Assistant entity reports, named in upper case with non-alphanumeric characters replaced by underscores (an app_name attribute becomes HA_APP_NAME). A small set of metadata and high-churn attributes is skipped (friendly_name, icon, device_class, supported_features, attribution, entity_picture, and media position), and at most 100 are exposed per entity.
  • The Relay State connection accepts Control4 relay consumer drivers; close = on, open = off.

Troubleshooting

  • Gateway Not Found: add the gateway driver first, or check the openhac4 Gateway connection in Connections > Control/AV.
  • Entity list empty: the gateway is not connected to Home Assistant yet, or has no switch entities. Check the gateway's Connection Status, then run Refresh Entity List here.
  • State stuck on Unavailable: either the entity is unavailable in Home Assistant, or the selected entity id does not exist. A typo produces the same result. Confirm the entity id against Home Assistant.
