Home Assistant Binary Sensor (openhac4)

Presents a Home Assistant binary_sensor entity in Control4 as a contact sensor provider. Bind a Control4 sensor driver such as door contact, motion, or moisture to the Contact State connection to surface it in navigators. Requires the openhac4 Gateway driver, installed and connected.

Setup

  1. Install and connect the Home Assistant Gateway (openhac4) driver first.
  2. Add this driver, or let the gateway's Import Devices action add it.
  3. Pick the binary_sensor entity in the Entity property. If the list is empty, run the Refresh Entity List action. Entity ID accepts a manually typed entity id, and is what the driver actually stores; picking from the list writes into it, so choose from the list last if you use both.
  4. Optionally add a Control4 contact-type driver such as Door Contact Sensor and bind it to this driver's Contact State connection so the sensor shows in navigators.
  5. Set Invert to On if breached/clear reads backwards for this device.

Programming

  • Events: Sensor Breached, Sensor Reset, Offline. Events fire on real state transitions only, not on project load.
  • Variable: STATE, true when breached.
  • The driver also creates a read-only HA_<ATTRIBUTE> variable for each attribute the Home Assistant entity reports, named in upper case with non-alphanumeric characters replaced by underscores (an app_name attribute becomes HA_APP_NAME). A small set of metadata and high-churn attributes is skipped (friendly_name, icon, device_class, supported_features, attribution, entity_picture, and media position), and at most 100 are exposed per entity.

Troubleshooting

  • Gateway Not Found: add the gateway driver first, or check the openhac4 Gateway connection in Connections > Control/AV.
  • Entity list empty: the gateway is not connected to Home Assistant yet, or has no binary_sensor entities. Check the gateway's Connection Status, then run Refresh Entity List here.
  • State reads backwards: Home Assistant device classes disagree about what "on" means; flip the Invert property.
