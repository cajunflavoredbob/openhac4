Home Assistant Select (openhac4)

Two-way bridge for a Home Assistant select entity, a named-option picker such as thermostat comfort modes, input selects, or vacuum fan modes. It has no navigator presence; it exists to drive and read the selection from Control4 programming.

Setup

  1. Add this driver to the project. It finds the openhac4 gateway automatically.
  2. Set Entity to the Home Assistant select entity, or type its id into Entity ID. Use Refresh Entity List if it is not listed yet.
  3. Detected Options shows the entity's options, and a Control4 programming event is created for each one.

Programming

  • Event: State Unavailable, when the entity goes unavailable in Home Assistant.
  • Read: under this driver's events you will see one event per option; program against them, for example "When Cool then...". Current Selection shows the active option.
  • Set: the Set Option action/command picks from the entity's live options and applies it in Home Assistant.
  • The driver also creates a read-only HA_<ATTRIBUTE> variable for each attribute the Home Assistant entity reports, named in upper case with non-alphanumeric characters replaced by underscores (an app_name attribute becomes HA_APP_NAME). A small set of metadata and high-churn attributes is skipped (friendly_name, icon, device_class, supported_features, attribution, entity_picture, and media position), and at most 100 are exposed per entity.
  • At most 64 options are exposed as Control4 events for one entity.

Troubleshooting

  • No options listed: confirm the entity is a select domain entity, then use Refresh Entity List.
  • Set Debug to On to reveal the logging controls for a trace of selection changes.
