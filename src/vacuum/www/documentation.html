Home Assistant Vacuum (openhac4)

Presents a Home Assistant vacuum entity in Control4 as an experience button. Tapping the button toggles between cleaning and returning to the dock. The full command set is available to programming. Requires the openhac4 Gateway driver, installed and connected.

Setup

  1. Install and connect the Home Assistant Gateway (openhac4) driver first.
  2. Add this driver, or let the gateway's Import Devices add it.
  3. Pick the vacuum entity from the Entity dropdown, or type the entity id into Entity ID. Run Refresh Entity List if the dropdown is empty.

Programming

  • Commands: Start, Pause, Stop, Return to Dock, Locate, Set Fan Speed, and Send Command. All seven are available in Programming. The Set Fan Speed picker lists the speeds the entity itself reports, so the names match your vacuum (Silent/Balanced/Turbo on one brand, low/medium/high on another). It fills in once the driver has received a state.
  • Send Command passes a raw command to the vacuum's integration through the Home Assistant send_command service. Set Command to the command name and Params to an optional JSON object of arguments. This drives room, zone, and segment cleaning on vacuums that support it. The exact command and params depend on the integration. For example, a vacuum might use Command segment_cleaning with Params {"segment_ids":[1,2]} to clean two rooms.
  • Events: Started Cleaning, Docked, Returning, Paused, Error, Offline.
  • Variables: VACUUM_STATE, FAN_SPEED, BATTERY_LEVEL.
  • The driver also creates a read-only HA_<ATTRIBUTE> variable for each attribute the Home Assistant entity reports, named in upper case with non-alphanumeric characters replaced by underscores (an app_name attribute becomes HA_APP_NAME). A small set of metadata and high-churn attributes is skipped (friendly_name, icon, device_class, supported_features, attribution, entity_picture, and media position), and at most 100 are exposed per entity.
  • Tapping the experience button starts cleaning when idle or docked, and sends the vacuum back to the dock while it is cleaning.

Notes

  • Battery is populated only if the vacuum entity reports battery_level. Some integrations, such as Valetudo, expose battery as a separate sensor entity instead, which you can add with the Sensor driver.

Troubleshooting

  • Gateway Not Found: add and connect the openhac4 Gateway driver first.
  • Entity list empty: the gateway is not connected to Home Assistant yet, or has no entities of this type. Check the gateway's Connection Status, then run Refresh Entity List.
  • State stuck on Unavailable: the entity is unavailable in Home Assistant, or the selected entity id does not exist. A typo produces the same result. Confirm the entity id against Home Assistant.
