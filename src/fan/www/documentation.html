Home Assistant Fan (openhac4)

Presents a Home Assistant fan entity in Control4 as a 4-speed fan. Control4 uses discrete speeds; this driver maps speeds 1-4 to 25/50/75/100 percent in Home Assistant, and speed 0 is off. Requires the openhac4 Gateway driver, installed and connected.

Setup

  1. Install and connect the Home Assistant Gateway (openhac4) driver first.
  2. Add this driver, or let the gateway's Import Devices add it.
  3. Pick the fan entity from the Entity dropdown, or type the entity id into Entity ID.

Programming

  • Commands: Turn On, Turn Off, Toggle, Set Speed from 0 to 4.
  • Events: Turned On, Turned Off, Offline.
  • Variable: SPEED, 0 to 4.
  • The driver also creates a read-only HA_<ATTRIBUTE> variable for each attribute the Home Assistant entity reports, named in upper case with non-alphanumeric characters replaced by underscores (an app_name attribute becomes HA_APP_NAME). A small set of metadata and high-churn attributes is skipped (friendly_name, icon, device_class, supported_features, attribution, entity_picture, and media position), and at most 100 are exposed per entity.
  • Actions: Set Oscillation, and Set Preset Mode offering the presets the entity advertises. These are Composer actions rather than programming commands.

Notes

  • The driver presents 4 speeds. Fans with a different number of native speeds are still controllable by percentage; the nearest speed is used.
  • Preset modes are reached through the Set Preset Mode action only. The driver does not advertise preset support to the fan proxy, so presets do not appear in the navigator fan UI.
  • Direction (forward and reverse) is not exposed.

Troubleshooting

  • Gateway Not Found: add and connect the openhac4 Gateway driver first.
  • Entity list empty: the gateway is not connected to Home Assistant yet, or has no entities of this type. Check the gateway's Connection Status, then run Refresh Entity List.
  • State stuck on Unavailable: the entity is unavailable in Home Assistant, or the selected entity id does not exist. A typo produces the same result. Confirm the entity id against Home Assistant.
