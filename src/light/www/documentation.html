Home Assistant Light (openhac4)

Presents a Home Assistant light entity in Control4 as a native dimmable light through the light_v2 proxy, with brightness, color, and color temperature. The driver detects the entity's capabilities from Home Assistant and adapts: an on/off-only light behaves as a switch, a dimmer exposes brightness, and color or tunable-white lights expose the color and color-temperature controls. Requires the openhac4 Gateway driver, installed and connected.

Setup

  1. Install and connect the Home Assistant Gateway (openhac4) driver first.
  2. Add this driver, or let the gateway's Import Devices add it.
  3. Pick the light entity in the Entity property. Run Refresh Entity List if it is empty. Entity ID accepts a manually typed entity id.
  4. The light appears in the Lighting experience and follows Home Assistant in real time.

Capabilities

The Detected Capabilities property shows what was found for the selected entity: on/off, dim, cct, or color. Because Control4 declares a light's capabilities at load time, this driver advertises the full color feature set, the same approach Control4's own Hue driver uses; the color controls have no effect on lights that do not support color.

Programming

  • Control the light from the Lighting experience and programming: on, off, level, and, where the entity supports it, color and color temperature.
  • Event: Offline, when the entity becomes unavailable.
  • Detected Capabilities and Current Level properties reflect the entity's abilities and current brightness.
  • Color Mode sets the colour space used when sending a colour: Auto (the default) sends CIE xy, XY is a synonym for Auto, and RGB or HS force that space instead for lights that ignore xy.
  • The driver also creates a read-only HA_<ATTRIBUTE> variable for each attribute the Home Assistant entity reports, named in upper case with non-alphanumeric characters replaced by underscores (an app_name attribute becomes HA_APP_NAME). A small set of metadata and high-churn attributes is skipped (friendly_name, icon, device_class, supported_features, attribution, entity_picture, and media position), and at most 100 are exposed per entity.

Troubleshooting

  • Gateway Not Found: add and connect the gateway driver first.
  • Color control does nothing: first check Detected Capabilities to confirm the entity reports colour at all. If it does but colour still has no effect, the light is rejecting the CIE xy values the driver sends by default; set the Color Mode property to RGB or HS to address it in that colour space instead.
  • Brightness looks off by a step: Home Assistant uses 0-255 and Control4 uses 0-100, so values are rounded when converted.
