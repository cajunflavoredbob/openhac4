Home Assistant Gateway (openhac4)

Connects Control4 to a Home Assistant instance over its websocket API. This gateway manages the connection and device discovery. Individual Home Assistant entities are handled by the openhac4 child drivers, which all require this gateway to be installed and connected first.

Setup

  1. In Home Assistant, open your user profile, then the Security tab, and create a Long-Lived Access Token. Copy it somewhere safe. Home Assistant shows it only once.
  2. In Composer Pro, use Driver > Add or Update Driver or Agent to load every openhac4 .c4z file, not just this gateway. That only loads them into Composer's driver database; you do not place them in the project by hand. Import Devices can only create a child driver that is already in the database, so a database holding only the gateway imports nothing.
  3. Add this driver to the project in Composer Pro.
  4. Set Home Assistant Address to the IP or hostname of your Home Assistant instance. A static IP or DHCP reservation is strongly recommended.
  5. Confirm Port. The Home Assistant default is 8123.
  6. Paste the token into Access Token.
  7. Connection Status should read "Connected - Authenticated" and Entity Count should populate within a few seconds.

Actions

  • Import Rooms: creates a Control4 room for each Home Assistant area on the project's floor. The driver remembers the rooms it created, so re-running does not duplicate them. It does not match or reuse rooms you created by hand. If a Home Assistant area name matches an existing room, a second room is created and you reconcile it manually.
  • Import Devices: opens a dialog to choose a Mode and filters. Preview logs the plan only and Import performs it. Filter by Domain, Area, Label, and Max. Label imports only entities carrying that Home Assistant label. Max caps a single run and the import is refused if the selection exceeds it. Each matching entity is added as a child driver, placed into the Control4 room for its Home Assistant area, so run Import Rooms first. Entities whose area has no room, or that have no area, are added to this gateway's room. Entities that already have a driver are skipped, as are sensor entities with no unit of measurement (these are usually diagnostic or text sensors). Devices are added one at a time and a large import can take a while, so it is safe to start it and leave it running.
  • Call Service: call any Home Assistant service. Available both here as an action and as a device-specific command in Programming. Set a Domain such as scene and a Service such as turn_on. Optionally set a target Entity and a Data JSON object of service data such as {"brightness":128}. Use it for scenes, scripts, automations, or any entity without its own driver.
  • Connect: force a reconnect now.
  • Discover Devices: refresh the entity list, areas, and labels from Home Assistant. Run it after adding an area or label in Home Assistant, or the Area and Label filters will still show what existed when the gateway connected.
  • Display Devices: print all known entities and their current states to the Lua output window.
  • Display Diagnostics: print connection details to the Lua output window.

Update Check

  • Check for Updates: Off by default. When On, the gateway asks the openhac4 GitHub releases page once a day whether a newer version exists and appends the result to Driver Version: "Update available: x.y.z" or "Up to Date". This is a single HTTPS request to api.github.com; nothing about your system is sent, and nothing is downloaded or installed. Updates are applied manually through Composer.

Troubleshooting

  • Status mentions "authentication failed": the token is wrong, expired, or was revoked. Create a new token and paste it again. The driver reconnects automatically when the property changes.
  • Stuck on "Connecting" or reconnect loop: verify the address and port are reachable from the controller itself, not just from your PC, and that nothing on the network blocks the controller's VLAN from reaching Home Assistant.
  • Import Devices creates nothing: the child driver .c4z files are missing from Composer's driver database. Load all of them with Driver > Add or Update Driver or Agent and run the import again. Preview mode is inspection only and never adds a driver, so a Preview that lists entities correctly while Import produces no devices points at this.
  • Use SSL: enable only if Home Assistant is served over HTTPS. With SSL Off the access token crosses the LAN in cleartext on every reconnect, so keep the gateway and Home Assistant on a trusted network segment.
  • Verify Certificate: with SSL on, set this On to verify the Home Assistant server certificate. It protects against an active man-in-the-middle but requires Home Assistant to present a certificate valid against a system CA. Leave it Off for a self-signed certificate, which encrypts the traffic but does not authenticate the server.
  • Access and trust: the access token is a Home Assistant credential with whatever rights the user who created it has, so prefer a token minted from a dedicated Home Assistant user rather than an administrator account. Note also that Control4 treats every driver in a project as trusted: any driver installed alongside this one can ask the gateway to call a Home Assistant service, so the gateway's authority is effectively shared with the whole project.
  • Debug: set to On to reveal the logging controls.
    • Log Mode picks live sinks. Print writes to the Lua output window, Log writes to the director log stream, or choose both.
    • Log Level sets the severity threshold. 3 - Info shows entity state changes, 4 - Trace adds connection detail (per-command dumps come from the child drivers, each with its own Debug property), and 5 - Debug adds raw websocket frames in both directions. Frames carrying a credential (the access token, or a service call with an alarm or lock code) are withheld from the log entirely, and long payloads are truncated.
    • Log Auto Off Minutes reverts Debug to Off after the configured number of minutes, 30 by default. Turning Debug Off also stops all logging.
